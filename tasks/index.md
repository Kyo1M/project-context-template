# タスク台帳

いま存在するタスクの一覧と状態。型の正本は [運用ガイド 4-3](../docs/guide/project-ops-guide.md#4-3-タスク台帳)。

- 行を足すのは `meeting-minutes` skill（議事録のネクストアクション表の全行）と人（会議外で出たタスク。出典に `チャット`／`壁打ち`＋日付）
- 議事録のネクストアクション表は会議当日の記録で、以後は更新しない。状態を持つのはこの台帳だけ
- ID: `T-<n>`（台帳全体の通し番号。進行中・完了・`archive/` を通じた最大値＋1。振った番号は変えない）
- 状態: `未着手`／`進行中`。着手・完了は担当者が直す。完了したら完了日を書いて完了節へ移す（見送りはタスク名の末尾に「（見送り）」）
