# タスク台帳

いま存在するタスクの一覧と状態。型の正本は [運用ガイド 4-3](../docs/guide/project-ops-guide.md#4-3-タスク台帳)。

- 行を足すのは `meeting-minutes` skill（議事録のネクストアクション表の全行）・`task-issue` skill（起票時に ID と状態を更新）・人（会議外で出たタスク。出典に `チャット`／`壁打ち`＋日付）
- 議事録のネクストアクション表は会議当日の記録で、以後は更新しない。状態を持つのはこの台帳だけ
- GitHub Issue を使う案件では、担当・期限・状態の正本は Issue・Project で、議事録作成時に AI が写す。人が状態を直すのは `表のみ` の行とツール無し案件だけ
- ID: Issue があれば `#n`（別リポジトリは `<短い名前>#n`）、起票前とツール無し案件は `yyyymmdd-#`（出典の日付＋連番。子は `yyyymmdd-#-#`）
- 状態: `未登録`／`表のみ`／`登録済み`／`進行中`／`完了`（完了節へ移す。見送りで閉じたものはタスク名の末尾に「（見送り）」）
